# Alish — Offline Exam System (системаи имтиҳонии оффлайн)

Веб-системаи имтиҳонӣ, ки дар шабакаи маҳаллии Wi-Fi **бе интернет** кор мекунад. Компютери асосӣ ҳамчун сервер кор мекунад; донишҷӯён бо телефон ё компютер тавассути браузер ворид мешаванд.

- **Забонҳо:** тоҷикӣ ва русӣ (TJ / RU)
- **Frontend:** React + TypeScript + Tailwind CSS + Material UI (Responsive, PWA)
- **Backend:** Node.js (бе бастаҳои беруна). Маълумот дар як файл: `backend/data/db.json`
- **Амният:** JWT, паролҳо бо scrypt ҳаш мешаванд (админ пароли аслиро намебинад)
- **PostgreSQL лозим нест.**

## 1. Чӣ лозим аст

Танҳо **Node.js LTS** (https://nodejs.org). Интернет танҳо барои насби аввал лозим аст.

## 2. Насб (як маротиба)

Дар Git Bash:
```
cd ~/Desktop/Alish
bash scripts/setup.sh
```
(ё дар Windows: `scripts\setup.bat`-ро ду маротиба клик кунед.)
Баъди «Тайёр!» интернет дигар лозим нест.

Барои дастрасии телефонҳо: `scripts\firewall.bat`-ро бо рости муш → *Run as administrator* иҷро кунед (як маротиба).

## 3. Оғози кор

Барои таҳия, frontend ва backend-ро якҷоя оғоз кунед:
```
npm run dev
```
Саҳифаро аз `http://localhost:5173` кушоед. Барои истифодаи оддӣ, сервери зеринро оғоз кунед:

```
cd ~/Desktop/Alish
bash scripts/start.sh
```
(ё `scripts\start.bat`.) Равзанаро то охири имтиҳон **накушед**. Равзана суроғаҳоро нишон медиҳад:

```
Дар ин компютер:  http://localhost:4000
Дар телефон:      http://192.168.0.10:4000
```

## Netlify

Netlify танҳо frontend-ро ҷойгир мекунад; backend бояд дар сервери алоҳидаи Node.js бо нигоҳдории доимии `backend/data` кор кунад. Дар Netlify тағйирёбандаи `VITE_API_URL`-ро ба origin-и backend гузоред (масалан `https://api.example.com`, бе `/api`). Дар backend `ALLOWED_ORIGINS`-ро ба origin-и сомонаи Netlify гузоред, масалан `https://your-site.netlify.app`.

Баъди тағйир додани тағйирёбандаҳо, Netlify-ро аз нав deploy кунед. Агар backend пайваст набошад, сомона ба ҷои хатои JavaScript паёми «backend пайваст нест»-ро нишон медиҳад.

## 5. Пайваст кардани телефонҳо тавассути Wi-Fi

1. Роутерро фурӯзон кунед (интернет лозим нест). Компютер ва телефонҳо ба **ҳамон як Wi-Fi** пайваст шаванд.
2. `start.sh`/`start.bat`-ро иҷро кунед ва сатри «Дар телефон: http://…:4000»-ро бинед.
3. Дар браузери телефон ҳамон суроғаро нависед (беҳтараш QR-код созед).
4. Агар кушода нашуд: `firewall.bat`-ро иҷро кунед; дар роутер «AP/Client Isolation»-ро хомӯш кунед; профили шабакаи Windows «Private» бошад; санҷед: `http://IP:4000/api/health`.
5. IP-и доимӣ: дар роутер (DHCP Reservation) ба компютер IP-и доимӣ диҳед.

## 6. Тартиби кор

1. **Гурӯҳ** созед (Гурӯҳҳо).
2. **Донишҷӯ** сабти ном мекунад → шумо **Донишҷӯён**-ро кушода ✓ (Тасдиқ) мезанед ва ба ӯ гурӯҳ таъин мекунед (таҳрир).
3. **Тест** созед → саволҳо илова кунед (ҳар савол — як ҷавоби дуруст) → гурӯҳро интихоб кунед → «Нашр шудааст»-ро фурӯзон кунед.
4. Донишҷӯ воридшуда тестро мебинад ва месупорад. Натиҷаҳо дар «Натиҷаҳо» (CSV содир кардан мумкин).

## 7. Қоидаҳои имтиҳон

- Ҷавобро баъди интихоб иваз кардан мумкин нест (сервер ҳам рад мекунад).
- Ҳар донишҷӯ ҳар тестро як маротиба месупорад. Аз нав супоридан танҳо бо иҷозати админ: *Натиҷаҳо → «Иҷозати аз нав супоридан»*.
- «Баромадан аз тест» имтиҳонро мебандад; бе иҷозати админ аз нав супоридан мумкин нест.
- Воридшавии **сеюм** ба имтиҳон аккаунтро маҳкам мекунад, то админ онро кушояд (*Донишҷӯён → ⋮ → Боз кардан*).
- Вақти имтиҳон дар сервер назорат мешавад. Ҷавобҳо захира мешаванд ва баъди навсозии саҳифа вақт ва ҷавобҳо мемонанд.
- Ҷавоби дуруст ҳеҷ гоҳ ба браузери донишҷӯ фиристода намешавад.

## 8. Нусхаи эҳтиётӣ

Ҳамаи маълумот дар `backend/data/db.json` аст. Нусха кардани ин файл = нусхаи пурраи эҳтиётӣ. Барои кӯчонидан ба компютери дигар: тамоми папкаро (ё танҳо `backend/data`) нусха кунед. Сервер худаш ҳар дақиқа `db.json.bak` месозад.

## 9. PWA ва HTTPS

Service Worker танҳо дар HTTPS ё `localhost` кор мекунад. Бо `http://192.168.x.x:4000` система пурра кор мекунад, танҳо кэшкунии офлайни барнома фаъол намешавад (ин барои кор лозим нест). HTTPS: бо `mkcert` сертификат созед ва дар `backend/.env` `SSL_KEY_PATH` ва `SSL_CERT_PATH`-ро нависед.

## 10. Масъалаҳои маъмул

| Мушкилӣ | Ҳал |
|---|---|
| `node: command not found` | Node.js-ро насб кунед, Git Bash-ро аз нав кушоед. |
| Саҳифа «Frontend build нашудааст» | `bash scripts/setup.sh`-ро иҷро кунед. |
| `Порти 4000 банд аст` | Равзанаи кӯҳнаи сервер кушода аст; пӯшед ё дар `backend/.env` `PORT=4001` нависед. |
| «Нет связи с сервером» | Сервер хомӯш аст: `bash scripts/start.sh`. Суроға `localhost:4000` бошад (на 5173). |
| Телефон намекушояд | Қисми 5. |
| Донишҷӯ ворид намешавад | Админ бояд тасдиқ кунад ва гурӯҳ диҳад. |
